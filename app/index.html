Your screen, your call.

Direct and encrypted. WebRTC encrypts media and control channels between peers. Pairing codes establish the connection; send them privately. Peers learn each other's network address.

No game hooks. Capture uses the runtime's screen-capture picker. Drift does not inject into games, install drivers, read game memory, or draw overlays. Compatibility depends on each game and its anti-cheat policy.

Honest about performance. Capture and encoding use resources. Start at 720p / 30 fps. H.264 is preferred; hardware encoding depends on the runtime, GPU and drivers. Stats show what the runtime reports.

No hosted room service. Exchange an invite and reply through a trusted channel. Optional public STUN discovers network routes. Some routers need a TURN relay; this version has no relay service. Rooms support up to four people, and close when the host leaves.

Nothing recorded. No recordings, analytics, accounts, or stored pairing codes. Only your name and stream preferences are saved on this PC.
